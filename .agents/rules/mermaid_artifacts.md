# Mermaid 다이어그램 아티팩트 출력 규칙

1. **대화 본문 내 Mermaid 직접 출력 금지**:
   - 챗봇 응답 메시지 본문에는 ````mermaid ... ```` 코드 블록을 직접 포함하지 않는다. (Chat UI에서는 그래픽으로 렌더링되지 않고 텍스트 코드 블록으로만 표시되어 가독성이 저하됨)

2. **반드시 아티팩트(Artifact)로 전달**:
   - 플로우차트, 시퀀스 다이어그램, 간트차트, 타임라인 등 Mermaid 시각화가 필요한 모든 콘텐츠는 반드시 `write_to_file`을 통해 아티팩트 디렉토리(`appDataDir/brain/<conversation-id>/...`)의 Markdown 문서에 작성한다.

3. **본문 보고 양식**:
   - 아티팩트 생성 후, 대화 본문에서는 해당 아티팩트의 링크(예: `[다이어그램 문서](file:///...)`)와 핵심 요약 내용만 간결하게 안내한다.
